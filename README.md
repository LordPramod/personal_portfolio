Personal Portfolio 🚀

Welcome to my personal portfolio! This project showcases my skills, experience, and projects in a clean and visually appealing manner. Built with modern tools and technologies, it serves as a reflection of my journey and accomplishments.

🛠️ Technologies Used

React: For building a dynamic and interactive user interface.

Vite: For a fast and optimized development experience.

Chakra UI: For sleek, responsive, and accessible design components.

🌟 Features

Responsive Design: Fully optimized for devices of all sizes.
Dynamic Content: Projects, skills, and contact sections are easily configurable.
Fast Performance: Leveraging Vite for a blazing-fast build and development process.
Theming Support: Customizable themes powered by Chakra UI.

📂 How to Run Locally
bash
Copy code

# Clone the repository

git clone https://github.com/LordPramod/personal_portfolio.git

# Navigate to the project folder

cd portfolio  

# Install dependencies

npm install  

# Start the development server

npm run dev  

# Open the project in your browser

# http://localhost:5173
